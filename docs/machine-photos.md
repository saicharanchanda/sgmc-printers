# Machine photos — how to add them

Each machine on the Infrastructure page has its own photo slot. Save the photo in
`src/assets/images/` with the exact file name below (`.jpg`, `.png` or `.webp`), rebuild,
and it replaces the "Photo coming soon" placeholder automatically. No code changes needed.
The site resizes and compresses photos itself, so upload the largest original you have.

## Use the client's OWN photos (not internet images)

The photos sent on WhatsApp on 2026-11-03 are manufacturer / brochure images found online:

- They are **copyrighted** by Komori, Müller Martini, etc. Using them on a commercial site without permission risks takedown notices.
- Some **don't match** the machine: the "Orient Web Offset – 4i" image shows **Ronald** branding, and the "L37" image is a Komori Lithrone.
- Visitors trust real photos of the actual shop floor far more than catalogue renders. That's the whole point of the "own building, own machines" message.

## How to shoot them (a phone is fine)

1. Daytime, lights on, floor tidy. Landscape orientation, 4:3.
2. Stand back so the whole machine is in frame, at chest height, slightly from the side (¾ view).
3. One extra shot with an operator working the machine (people make it feel alive).
4. Close-ups: printed sheets coming off the press, a stack of bound books, the CTP plate.
5. Also useful: building exterior, team photo in front of a press.

## How to send them without losing quality

WhatsApp compresses photos. Send them as **Document** (📎 → Document → pick the photos),
or share a Google Drive / Google Photos album link. Do **not** send screenshots.
